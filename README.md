# MorseBinaria

TDE 2 --- Implementar uma árvore binária onde cada nó corresponde a um símbolo do código Morse
== Integrantes:
-Thomas Sotti
-Luiz Fernando
-Arthur Schmitt
-Pedro Gouveia
== Funcionalidades:
Cadastrar o alfabeto e os números organizados em - e .
Campo digitar o código morse e ele traduzir esse código para um texto/palavra ao clicar no botão
